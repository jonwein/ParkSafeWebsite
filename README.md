# ParkSafe Legal Pages

Privacy Policy and Support pages for the ParkSafe iOS app.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`

## Deployment

This site is built with Jekyll and hosted on GitHub Pages. Push to `main` to deploy.

### Setup GitHub Pages

1. Go to repository Settings > Pages
2. Set Source to "Deploy from a branch"
3. Select `main` branch and `/ (root)` folder
4. Save

The site will be available at `https://[username].github.io/parksafe-legal/`

## Pages

- **Privacy Policy** (`/`) - App privacy policy
- **Support** (`/support/`) - FAQ and contact information
